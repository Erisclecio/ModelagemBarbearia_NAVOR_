# NAVØR | Modelagem de Dados

Projeto acadêmico do curso de **Análise e Desenvolvimento de Sistemas (ADS)**, desenvolvido em grupo para modelar o banco de dados de um futuro ERP para a **NAVØR Barbearia**.

O trabalho reúne o levantamento dos processos da empresa, requisitos e regras de negócio, fluxogramas e o Diagrama Entidade-Relacionamento (DER). A proposta é organizar informações de clientes, agendamentos, atendimentos, serviços, vendas, compras, estoque, pagamentos e comissões.
